# Gestão de Eventos - Associação Cultural das Artes (SGBD)

Este projeto consiste no planeamento, modelação e implementação de um Sistema de Base de Dados (SBD) relacional para o domínio de "Organização de Eventos com Inscrições". Desenvolvido sob o contexto da consultora tecnológica Nexus Data Solutions para a Associação Cultural das Artes (ACA), o sistema visa centralizar e automatizar a gestão de conferências, workshops, participantes, oradores e alocação de salas.

## Enunciado do Projeto

O objetivo deste projeto é o desenvolvimento completo de um SBD relacional, passando por todas as fases do ciclo de vida: análise e levantamento de requisitos, modelação conceptual (Diagrama ER), modelação lógica (Normalização até 3NF) e implementação física num Sistema de Gestão de Bases de Dados (SGBD).

O sistema desenvolvido responde às necessidades operacionais da ACA, eliminando redundâncias e erros manuais, suportando restrições de lotação de salas, prevenindo inscrições duplicadas e aplicando diferenciação financeira automática (através de funções e gatilhos/triggers). O projeto inclui ainda a criação de vistas (views) para facilitar o acesso à informação do dia a dia e procedimentos armazenados (stored procedures) para agilizar o registo de inscrições.
